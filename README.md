# Sun-Stone League

A mobile-first 3D Pok-Ta-Pok-inspired ball game built with Three.js and Vite.

## Play modes

- **Solo Challenge:** score as many rings as possible in 60 seconds.
- **1v1 vs Rival:** first player to three rings wins.

## Controls

- Desktop: WASD or arrow keys to move, mouse to aim, Space or click to strike.
- Mobile: virtual joystick to move and the STRIKE button to hit.

## Run locally

```bash
npm install
npm run dev
```

## Build and publish

```bash
npm run build
```

The Vite base path is configured for GitHub Pages project hosting.
